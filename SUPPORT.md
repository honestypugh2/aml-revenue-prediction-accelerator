# Support

This project is provided as a reusable accelerator and educational resource. It
is maintained on a best-effort basis.

## How to get help

1. **Read the docs.** Start with the [README](README.md) and the
   [`docs/`](docs/) directory (architecture, modeling, deployment, security,
   governance, operations, workshops).
2. **Run the offline path.** Most questions about behavior can be answered by
   running `make data && make train` and the [educational UI](README.md#quickstart-fully-offline).
3. **Search existing issues** before opening a new one.
4. **Open an issue** using the provided templates for bugs or feature requests.

## What is in and out of scope

**In scope:** the accelerator code, offline synthetic workflow, documentation,
workshop materials, and infrastructure templates.

**Out of scope:** organization-specific data, production configuration, live
Azure/Fabric tenant issues, and anything requiring real credentials. Cloud steps
are opt-in and must be validated in your own subscription.

## Response expectations

There is no service-level agreement. Maintainers triage issues and pull requests
as time permits.
